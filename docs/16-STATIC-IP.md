# 16 — Στατική IP για την Pointer

Η Pointer δίνει πρόσβαση στο API **μόνο σε δηλωμένη IP**. Το Railway δεν έχει
σταθερή IP εξόδου στα φθηνά πλάνα — αλλάζει σε κάθε deploy. Χωρίς στατική IP
δεν παίρνουμε ούτε sandbox.

## Τι να νοικιάσεις

Το φθηνότερο αξιόπιστο είναι **Hetzner Cloud**. Ένα μικρό μηχάνημα κάνει
περίπου **€4/μήνα** και έχει **δική του σταθερή IPv4**.

1. Λογαριασμός: https://console.hetzner.cloud
2. **New Project** → όνομα `vitrina`
3. **Add Server**:
   - **Location:** Falkenstein ή Helsinki (και τα δύο ΕΕ — μένουμε εντός ΕΕ για GDPR)
   - **Image:** Ubuntu 24.04
   - **Type:** το μικρότερο διαθέσιμο (CX/CAX entry) — μας φτάνει, δεν σερβίρει κίνηση
   - **Networking:** άφησε **ενεργό το IPv4** (αυτό είναι που πληρώνουμε — μόνο IPv6 δεν κάνει)
   - **SSH key:** ανέβασε το δικό σου (πιο ασφαλές από κωδικό)
4. Create. Σε ~30 δευτερόλεπτα έχεις IP της μορφής `95.217.x.x`

> Εναλλακτικές στην ίδια τιμή: Contabo, Vultr, DigitalOcean. Καμία διαφορά για
> εμάς — θέλουμε μόνο μία σταθερή IP.

**Αυτή την IP στέλνεις στην Pointer** για να σου ανοίξουν το sandbox.

## Πώς τη χρησιμοποιούμε

Δύο τρόποι. Ο κώδικας υποστηρίζει **και τους δύο** — δεν χρειάζεται αλλαγή.

### Α) Τρέχεις τις εντολές domain πάνω στο μηχάνημα *(απλούστερο)*

Οι αγορές domain γίνονται ούτως ή άλλως χειροκίνητα, μία φορά την ημέρα.

```bash
ssh root@Η_IP_ΣΟΥ
apt update && apt install -y python3 python3-pip git
git clone <το repo> vitrina && cd vitrina
# .env με POINTER_USERNAME / POINTER_PASSWORD / POINTER_NS1 / POINTER_NS2
python3 scripts/orders.py
```

Καμία ρύθμιση δικτύου, καμία τρύπα ασφαλείας. Μειονέκτημα: τα κλειδιά ζουν και
στο μηχάνημα, και δουλεύεις μέσω SSH.

### Β) Το μηχάνημα ως proxy, ο κώδικας μένει στο Railway

```bash
ssh root@Η_IP_ΣΟΥ
apt update && apt install -y tinyproxy
# /etc/tinyproxy/tinyproxy.conf:
#   Port 8888
#   Allow <η IP του Railway ή 0.0.0.0/0 ΜΟΝΟ με BasicAuth>
#   BasicAuth vitrina ΕΝΑΣ_ΔΥΝΑΤΟΣ_ΚΩΔΙΚΟΣ
systemctl restart tinyproxy
ufw allow 8888/tcp && ufw enable
```

Και στο Railway:

```
POINTER_PROXY=http://vitrina:ΚΩΔΙΚΟΣ@Η_IP_ΣΟΥ:8888
```

**ΜΟΝΟ** οι κλήσεις προς Pointer περνούν από εκεί — όλα τα υπόλοιπα μένουν όπως
είναι ([src/registrar_pointer.py](../src/registrar_pointer.py), σταθερά `PROXY`).

⚠️ Χωρίς `BasicAuth` ο proxy είναι ανοιχτός σε όλο το ίντερνετ και θα τον
χρησιμοποιήσουν τρίτοι μέσα σε ώρες. Βάλε κωδικό.

## Ποιον να διαλέξεις

**(Α)** στην αρχή: τίποτα να ρυθμίσεις, τίποτα να σπάσει. Οι αγορές είναι λίγες.

**(Β)** όταν θέλουμε ο πελάτης να πληρώνει και το domain να βγαίνει **μόνο του**
χωρίς εσένα. Τότε ο κώδικας πρέπει να τρέχει στο Railway.

## Κόστος

| | |
|---|---|
| Hetzner μικρό μηχάνημα | ~€4/μήνα |
| Railway Pro (εναλλακτικά) | $20/μήνα, στατικές IP χωρίς επιπλέον χρέωση |

Το Railway Pro συμφέρει **μόνο** αν το χρειαστούμε και για άλλους λόγους.
Σκέτο για τη στατική IP, το μηχάνημα των €4 είναι πεντακάσια φορές φθηνότερο.

## Πριν το ζητήσεις

Ο adapter είναι **γραμμένος και ελεγμένος**:

```bash
python scripts/test_pointer.py     # 23/23 — χωρίς να χρειάζεται το API τους
```

Δοκιμάζει checksums, μορφή XML, ελληνικά UTF-8, τον διαχωρισμό sandbox/παραγωγής
και ότι ο κωδικός δεν φεύγει ποτέ ωμός. Μόλις έρθει η πρόσβαση, αλλάζει μόνο το
`API_URL` σε πραγματικό — τίποτα άλλο.
