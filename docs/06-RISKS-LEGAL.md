# 06 — Ρίσκα & Νομικά

## 🔴 Ρίσκο #1 — Meta App Review (το πιο σοβαρό τεχνικά)

Το αυτόματο posting σε Facebook/Instagram **δεν** είναι απλό API call:

- Δουλεύει **μόνο** με **Business/Creator accounts** συνδεδεμένα με Facebook Page.
- Χρειάζεσαι **App Review από τη Meta** (εγκρίνουν την εφαρμογή σου).
- Personal accounts → **αδύνατο** το αυτόματο post. Μόνο business.

**Τι να κάνεις:**
- Ξεκίνα το App Review **από μέρα 1** (Φάση 1) — παίρνει χρόνο.
- Χρειάζεσαι: privacy policy, καθαρό use-case, demo video.
- Χρησιμοποίησε το **επίσημο Meta MCP** (από 29/4/2026) που απλοποιεί το posting.
- Token management: τα FB/IG tokens λήγουν → χρειάζεσαι auto-refresh (μέσω vault).

## 🟠 Ρίσκο #2 — X/Twitter API

- Το X API είναι **ακριβό** (~$100/μήνα). **Άστο στην αρχή.**
- Στην Ελλάδα μικρό κοινό για μικρομάγαζα. **FB + Instagram φτάνουν.**

## 🟠 Ρίσκο #3 — Ποιότητα AI εικόνων

- Για ταβέρνα/καφέ ο κόσμος θέλει **αληθινό φαγητό**, όχι AI.
- Λύση: ο πελάτης ανεβάζει 3-4 φωτό/βδομάδα, το AI κάνει captions + λίγες AI εικόνες.

## 🟡 Ρίσκο #4 — GDPR / Προσωπικά δεδομένα

- Διαχειρίζεσαι: στοιχεία επιχείρησης, tokens social, ίσως φωτό πελατών.
- **Best practices:**
  - EU hosting (Supabase EU region).
  - Encryption at rest.
  - Tokens **μόνο** σε vault (ποτέ σε prompts/logs/agent config).
  - Καθαρή privacy policy + όροι χρήσης.
  - Μην κρατάς ό,τι δεν χρειάζεσαι.
- Καλό νέο: το να το κάνεις σωστά **είναι moat** — εμπιστοσύνη > «ρώτα το ChatGPT».

## 🟡 Ρίσκο #5 — Ανταγωνισμός (αντιγραφή)

Επειδή τα building blocks είναι έτοιμα/δωρεάν, ο τεχνικός κόπος είναι μικρός →
**εύκολο να σε αντιγράψουν.** Το moat σου ΔΕΝ είναι ο κώδικας. Είναι:
1. **Ελληνική εξειδίκευση** (τόνος, templates, `.gr`) που οι ξένοι δεν έχουν.
2. **Διανομή** — σχέσεις με μαγαζιά, word-of-mouth, FB groups.
3. **Managed μοντέλο** — «δεν ασχολούμαι εγώ» (οι μεγάλοι δίνουν DIY εργαλεία).

## 🟢 Ρίσκο #6 — Κόστος που ξεφεύγει

- Βάλε όρια στο free tier.
- Μην τρέχεις Opus σε hot path.
- Prompt caching για σταθερό context.
- Φωτό πελάτη αντί για AI εικόνες όπου γίνεται.
