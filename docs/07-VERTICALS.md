# 07 — Industry Presets (έτοιμα patterns ανά επάγγελμα)

> Η ιδέα: ο agent **δεν ξεκινά από το μηδέν** ούτε ρωτάει τα προφανή. Κάθε τύπος
> επιχείρησης έχει ένα **έτοιμο preset**: ποια sections έχει το site, τι πληροφορίες
> χρειάζεται, τι είναι αυτονόητο (χάρτης, τηλέφωνο), τι πρέπει ΟΝΤΩΣ να ρωτηθεί.

## Γιατί μετράει
- **Καλύτερο προϊόν:** ο οδοντίατρος δεν θέλει «μενού», ο ταβερνιάρης δεν θέλει «λίστα υπηρεσιών».
- **Λιγότερες ερωτήσεις:** ρωτάμε μόνο τα αναγκαία → πιο εύκολο onboarding για μη-τεχνικό.
- **Συνέπεια & ταχύτητα:** σταθερή ποιότητα, γρήγορο site.

## Πώς δουλεύει (smart defaults)

```
Ο agent: "Τι μαγαζί έχεις;" → "οδοντίατρος"
   → φορτώνει το preset "οδοντιατρείο"
   → ξέρει ΗΔΗ: sections (υπηρεσίες, ραντεβού, ωράριο, χάρτης, τηλέφωνο),
     τόνος (επαγγελματικός/καθησυχαστικός), social θέματα (συμβουλές υγιεινής)
   → ΣΥΜΠΛΗΡΩΝΕΙ μόνος ό,τι είναι αυτονόητο (χάρτης+τηλέφωνο πάντα)
   → ΡΩΤΑΕΙ μόνο: διεύθυνση, τηλέφωνο, ωράριο, ποιες υπηρεσίες
```

## Δομή ενός preset

```yaml
preset: οδοντιατρείο
site_sections:        # τι έχει το site
  - hero (όνομα + "κλείσε ραντεβού")
  - υπηρεσίες
  - σχετικά με τον γιατρό
  - ωράριο
  - χάρτης (Google Maps)        # ΑΥΤΟΝΟΗΤΟ — μη ρωτάς αν θέλει
  - τηλέφωνο / call button       # ΑΥΤΟΝΟΗΤΟ
must_ask:             # ΜΟΝΟ αυτά ρωτάει
  - διεύθυνση
  - τηλέφωνο
  - ωράριο
  - λίστα υπηρεσιών
auto_assume:          # τα βάζει χωρίς ερώτηση
  - χάρτης: ναι
  - call button: ναι
  - φόρμα ραντεβού: ναι
tone: επαγγελματικός, καθησυχαστικός
social_themes:        # για τα καθημερινά posts
  - συμβουλές στοματικής υγιεινής
  - "γνωρίστε την ομάδα μας"
  - πριν/μετά (με συγκατάθεση)
no_go:                # τι ΔΕΝ ταιριάζει
  - "μενού" / λίστα προϊόντων
```

## Τα presets που χρειάζεσαι (ξεκίνα με 5-6)

| Preset | Sections-κλειδιά | Must-ask | Αυτονόητα | Social θέματα |
|--------|------------------|----------|-----------|----------------|
| **Ταβέρνα/Εστιατόριο** | μενού, κρατήσεις, ωράριο, χάρτης | μενού/πιάτα, τηλ, ωράριο | χάρτης, τηλ, φωτό φαγητού | πιάτα ημέρας, παρασκήνιο |
| **Καφέ** | ατμόσφαιρα, μενού, ωράριο, χάρτης | περιοχή, ωράριο | χάρτης, τηλ | πρωινό, ατμόσφαιρα |
| **Οδοντίατρος/Ιατρείο** | υπηρεσίες, ραντεβού, ωράριο, χάρτης | υπηρεσίες, τηλ, ωράριο | χάρτης, τηλ, φόρμα ραντεβού | συμβουλές υγείας, η ομάδα |
| **Μάστορας** (υδραυλικός/ηλεκτρολόγος) | υπηρεσίες, περιοχές, τηλ | υπηρεσίες, περιοχές, τηλ | call button, "αυθημερόν" | tips, ολοκληρωμένες δουλειές |
| **Κομμωτήριο/Beauty** | υπηρεσίες, ραντεβού, gallery, χάρτης | υπηρεσίες, τηλ, ωράριο | χάρτης, ραντεβού, gallery | looks, προσφορές |
| **Κατάστημα (γενικό)** | προϊόντα, ωράριο, χάρτης | τι πουλάει, ωράριο | χάρτης, τηλ | νέα προϊόντα, προσφορές |

## Πού ζει αυτό στον κώδικα/skills

Τα presets μπαίνουν στα **skills** (όχι σε hardcoded κώδικα — εύκολο να τα βελτιώνεις):

- `greek-website/SKILL.md` → περιγράφει πώς να επιλέξει preset + το πίνακα παραπάνω
- `greek-website/templates/` → ένα HTML template ανά preset (taverna.html, dentist.html, mastoras.html…)
- `brand-builder-gr/SKILL.md` → ανά preset: τόνος + social θέματα
- `social-post-gr/SKILL.md` → ανά preset: τι ποστάρει (ήδη το έχει ανά τύπο)

## Best practice
**Ξεκίνα με 3 presets** (ταβέρνα, καφέ, μάστορας — τα πιο συχνά), όχι 20.
Πρόσθεσε νέα όταν εμφανιστεί πελάτης που τα χρειάζεται. Κάθε νέο preset = update στο skill.

> Αυτό είναι **μέρος του moat σου**: τα ελληνικά presets (τι θέλει ένα ελληνικό
> οδοντιατρείο/ταβέρνα) είναι ακριβώς αυτό που οι ξένοι builders (Wix/Lovable) δεν έχουν.
