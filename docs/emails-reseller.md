# Emails για reseller .gr domains

Στείλ' τα **και στα δύο** — όποιος απαντήσει πρώτος με χρησιμοποιήσιμο API, τον βάζουμε.
Ο adapter (`src/registrars.py`) είναι ήδη έτοιμος· ό,τι κι αν διαλέξουμε μπαίνει σαν βύσμα.

**Γιατί ρωτάμε αυτά τα 5:** χωρίς sandbox δεν δοκιμάζουμε χωρίς να ξοδέψουμε· χωρίς
δυνατότητα να ορίσουμε registrant τον πελάτη, τα domain γράφονται στο δικό μας όνομα
(μοιάζει με ομηρία και χάνεται η εμπιστοσύνη)· και η προκαταβολή καθορίζει αν αξίζει
τώρα ή στους 30 πελάτες.

## 1) Papaki — `sales@papaki.gr` / φόρμα μεταπωλητών

**Θέμα:** Αίτημα για Reseller API — αυτοματοποιημένη κατοχύρωση .gr

Καλησπέρα σας,

Λέγομαι Άγγελος Παπαδόπουλος και αναπτύσσω το **Vitrina** (getvitrina.gr), υπηρεσία
που φτιάχνει και συντηρεί επαγγελματικά websites για μικρές ελληνικές επιχειρήσεις
(ταβέρνες, τεχνίτες, κομμωτήρια κ.λπ.) με συνδρομή.

Κάθε πελάτης χρειάζεται το δικό του **.gr domain**. Σήμερα τα κατοχυρώνουμε
χειροκίνητα· θέλουμε να το αυτοματοποιήσουμε μέσω API.

Θα ήθελα να μάθω:

1. **Πρόσβαση στο API** — πώς αποκτούμε reseller λογαριασμό και τεκμηρίωση;
2. **Sandbox** — υπάρχει περιβάλλον δοκιμών χωρίς πραγματικές χρεώσεις;
3. **Registrant τα στοιχεία του πελάτη** — μπορούμε μέσω API να ορίζουμε ως κάτοχο
   τον ίδιο τον πελάτη (όχι εμάς); Είναι σημαντικό: θέλουμε ο πελάτης να **κατέχει**
   το domain του.
4. **Χονδρική τιμή** .gr (1 έτος) και τιμή ανανέωσης.
5. **Ελάχιστη προκαταβολή / πάγιο** για τον reseller λογαριασμό.

Ξεκινάμε με μικρό όγκο (5-10 domain/μήνα) με στόχο σημαντική αύξηση.

Ευχαριστώ για τον χρόνο σας,
Άγγελος Παπαδόπουλος — Vitrina

## Όταν απαντήσουν
Δώσε μου: **API base URL, κλειδί, και το endpoint κατοχύρωσης**. Τα βάζω στο `.env`
(`PAPAKI_API_BASE`, `PAPAKI_API_KEY`, `PAPAKI_CONTACT_ID`), γυρίζω το
`DOMAIN_REGISTRAR=papaki` και η αγορά γίνεται αυτόματα μέσα στη ροή πληρωμής.

⚠️ **Μη στείλεις ποτέ κλειδιά σε chat/email προς εμένα** — μόνο στο `.env`.
