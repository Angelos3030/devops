# Emails για reseller .gr domains

Στείλ' τα **και στα δύο** — όποιος απαντήσει πρώτος με χρησιμοποιήσιμο API, τον βάζουμε.
Ο adapter (`src/registrars.py`) είναι ήδη έτοιμος· ό,τι κι αν διαλέξουμε μπαίνει σαν βύσμα.

**Γιατί ρωτάμε αυτά τα 5:** χωρίς sandbox δεν δοκιμάζουμε χωρίς να ξοδέψουμε· χωρίς
δυνατότητα να ορίσουμε registrant τον πελάτη, τα domain γράφονται στο δικό μας όνομα
(μοιάζει με ομηρία και χάνεται η εμπιστοσύνη)· και η προκαταβολή καθορίζει αν αξίζει
τώρα ή στους 30 πελάτες.

## Όταν απαντήσουν
Δώσε μου: **API base URL, κλειδί, και το endpoint κατοχύρωσης**. Τα βάζω στο `.env`
(`PAPAKI_API_BASE`, `PAPAKI_API_KEY`, `PAPAKI_CONTACT_ID`), γυρίζω το
`DOMAIN_REGISTRAR=papaki` και η αγορά γίνεται αυτόματα μέσα στη ροή πληρωμής.

⚠️ **Μη στείλεις ποτέ κλειδιά σε chat/email προς εμένα** — μόνο στο `.env`.

### ⚠️ Το εμπόδιο: στατική IP

Το API μας τρέχει στο Railway, που **δεν δίνει σταθερή IP εξόδου** στα φθηνά
πλάνα — η IP αλλάζει σε κάθε deploy. Χωρίς αυτήν δεν παίρνουμε ούτε sandbox.

Επιλογές (επαληθευμένες 06/08):
1. **Railway Pro — $20/μήνα, στατικές IP χωρίς επιπλέον χρέωση.**
   Settings → Networking → Enable Static IPs. Δίνει **3 IPv4** με load balancing
   (τους τις στέλνουμε και τις τρεις). Καμία νέα υποδομή, ο κώδικας μένει εκεί
   που είναι. Προσοχή: αλλαγή region = αλλαγή IP, και δεν εγγυώνται αποκλειστικές.
   https://docs.railway.com/networking/static-outbound-ips
2. **Μικρό VPS ως proxy** — ~4€/μήνα (Hetzner). Φθηνότερο, αλλά ένα ακόμα
   μηχάνημα να συντηρείς και ο κώδικας των domain φεύγει από το Railway.
3. ~~Cloudflare Worker~~ — δεν εγγυάται σταθερή IP, δεν κάνει για whitelist.

**Πρόταση: (1)**, ΑΝ πάμε Pro ούτως ή άλλως. Αλλιώς (2). Στα €14.99/πελάτη,
τα $20 είναι μιάμιση συνδρομή — δεν αξίζει πριν υπάρχουν πελάτες.

Πρόταση: (1). Είναι το μόνο που δεν εξαρτάται από τιμολόγιο τρίτου.

### Κατάσταση υλοποίησης
- ✅ **Adapter γραμμένος**: [src/registrar_pointer.py](../src/registrar_pointer.py)
  — login/logout, domain-check, contact-domain.create, domain.create, updatens.
  Τα checksums επαληθεύτηκαν ότι βγαίνουν ίδια με το επίσημο PHP παράδειγμά τους.
- ⏳ Αδοκίμαστο σε ζωντανό API — περιμένει sandbox (στατική IP).

Τρία που ΔΕΝ γράφει η τεκμηρίωσή τους και τα βρήκαμε στο `pointer_api.php`:
- URL: `https://www.pointer.gr/api`
- Sandbox = header `testserver: 1`, όχι άλλο endpoint
- Το checksum θέλει το όνομα ΜΕΘΟΔΟΥ (`domainCheck`), όχι το XML tag (`domain-check`)

### Σειρά ενεργειών
1. Άνοιγμα λογαριασμού Pointer + μικρό υπόλοιπο
2. Στατική IP → τους τη στέλνουμε → sandbox
3. Adapter πάνω στο API τους, με τη ροή που ήδη έχουμε (orders.py → link_domain_cf.py)
4. Πρώτα domain πελατών → ζητάμε καλύτερη κλίμακα

## 🔬 Διάγνωση sandbox (06/08/2026)

Πήραμε πρόσβαση: dev panel + API στο `dev.pointer.gr`, €1000 δοκιμαστικό
υπόλοιπο, μόνο `.gr`. Το `dev.pointer.gr` δέχεται **μόνο** τη δηλωμένη IP
(95.217.189.29) — από αλλού βγάζει 403 nginx, οπότε ακόμα και το panel θέλει
σήραγγα μέσω του server.

**Το API δεν συνδέεται.** Επιστρέφει σταθερά `[105] Client does not exists`.

Το απομονώσαμε με τρεις ανεξάρτητους ελέγχους:

| Έλεγχος | Αποτέλεσμα | Τι αποδεικνύει |
|---|---|---|
| Σκόπιμα **λάθος** κωδικός στο dev | ίδιο `105` (όχι `102`) | Η αναζήτηση χρήστη αποτυγχάνει ΠΡΙΝ τον έλεγχο κωδικού |
| Ίδιο αίτημα στο **production** | `[102] Wrong Credentials` | Η μορφή XML/checksum μας είναι **σωστή** |
| 4 διαδρομές × 3 τιμές `testserver` | όλα `105` στο dev | Δεν είναι θέμα endpoint ή header |

Δοκιμάστηκαν επίσης: `username` μέσα στο `<login>`, κωδικός χωρίς md5,
username χωρίς `@domain`. Ίδιο αποτέλεσμα.

**Συμπέρασμα:** ο λογαριασμός υπάρχει στο dev panel (βλέπουμε τα credits) αλλά
δεν αντιστοιχεί σε API client στο dev περιβάλλον τους. Χρειάζεται ενέργεια από
την Pointer — μας είχαν ζητήσει ρητά να τους ενημερώνουμε για τέτοια.

Ο κωδικός `105` **δεν υπάρχει στο API.md** τους.
