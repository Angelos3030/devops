# Conversion Copy GR

## Στόχος
Να γράφεις copy που καταλαβαίνει ο Έλληνας μικροεπαγγελματίας και ο πελάτης του.
Όχι SaaS jargon. Όχι γενικότητες. Πάντα συγκεκριμένη αξία.

## Formula
Για κάθε section σκέψου:

```text
Ποιος είναι ο πελάτης;
Τι θέλει τώρα;
Τι τον σταματάει;
Ποια απλή πράξη πρέπει να κάνει;
```

## Vitrina voice
- Απλό, καθαρό, ανθρώπινο.
- “Το αναλαμβάνουμε” αντί για “χρησιμοποίησε την πλατφόρμα”.
- “Πες μας το μαγαζί σου” αντί για “δημιούργησε account”.
- “Δες demo” αντί για “ξεκίνα trial” όταν πουλάμε σε μη τεχνικούς.

## Patterns που δουλεύουν
| Χρήση | Pattern |
|---|---|
| Hero | Αποτέλεσμα + αφαίρεση κόπου |
| CTA | Δες/φτιάξε/κλείσε, όχι αφηρημένο “μάθε περισσότερα” |
| Pricing | Τι παίρνει πρακτικά ο πελάτης |
| Trust | Τοπικότητα, απλότητα, κανένα κρυφό κόστος |
| Offer | Συγκεκριμένη αφορμή: σήμερα, αυτή την εβδομάδα, πρώτο ραντεβού |

## Μην γράφεις
- “Ανακαλύψτε τη δύναμη της τεχνητής νοημοσύνης”.
- “Ολοκληρωμένη λύση ψηφιακού μετασχηματισμού”.
- “Κορυφαία ποιότητα στις καλύτερες τιμές”.
- Μεγάλα paragraphs. Κάθε section θέλει γρήγορο σκανάρισμα.
