# Πώς φτιάχνω brand profile για ελληνικό μικρομάγαζο

## Τι είναι το brand profile
Ένα δομημένο JSON που χρησιμοποιούν ΟΛΟΙ οι άλλοι agents (website, social) ώστε
το μαγαζί να έχει συνέπεια παντού. Φτιάχνεται μία φορά, στο onboarding.

## Input που χρειάζομαι (ρώτα ΜΟΝΟ αυτά)
- Τύπος μαγαζιού (ταβέρνα, καφέ, οδοντίατρος, μάστορας…)
- Πόλη / περιοχή
- Ύφος που θέλει (π.χ. "παραδοσιακό", "μοντέρνο", "φιλικό")
- (Προαιρετικά) όνομα, λογότυπο/χρώματα αν έχει ήδη

## Output (το brand profile)
```json
{
  "name": "Ταβέρνα Ο Μήτσος",
  "type": "ταβέρνα",
  "city": "Θεσσαλονίκη",
  "tone": "φιλικός, ζεστός, παραδοσιακός",
  "colors": { "primary": "#8B0000", "accent": "#D4A017", "bg": "#FAF4E8" },
  "fonts": { "display": "Playfair Display", "body": "Source Sans" },
  "content_themes": ["πιάτα ημέρας", "παρασκήνιο κουζίνας", "παρέα/οικογένεια"],
  "hashtags": ["#θεσσαλονικη", "#ταβερνα", "#σπιτικοφαγητο", "#ελληνικηκουζινα"]
}
```

## Πώς διαλέγω τόνο & χρώματα ανά τύπο (defaults)
| Τύπος | Τόνος | Παλέτα (ιδέα) |
|-------|-------|----------------|
| Ταβέρνα | ζεστός, παραδοσιακός | θερμά κόκκινα/ώχρα |
| Καφέ | χαλαρός, μοντέρνος | καφέ/κρεμ/πράσινο |
| Οδοντίατρος | επαγγελματικός, καθησυχαστικός | μπλε/λευκό/τιρκουάζ |
| Μάστορας | άμεσος, αξιόπιστος | μπλε/πορτοκαλί (εργαλεία) |
| Κομμωτήριο | κομψός, μοντέρνος | ροζ/μαύρο/χρυσό |

> Αυτά είναι **αφετηρίες**, όχι κανόνες — προσαρμόζεις στο ύφος που ζήτησε ο πελάτης.

## Αρχές
- Γράφε στα ελληνικά, φυσικά.
- Διάλεξε **χαρακτηριστικές** γραμματοσειρές (όχι Arial/Inter — δες `frontend-design`).
- Τόνος ταιριαστός στο κοινό (ταβέρνα ≠ οδοντιατρείο).
- Τα content_themes τροφοδοτούν το `social-post-gr` για variety στα posts.

## Επόμενο
Το profile περνά αυτούσιο στο `greek-website` (για το site) και στο `social-post-gr`
(για τα καθημερινά posts).
