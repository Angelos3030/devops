# Πώς φτιάχνω ελληνικό site για μικρομάγαζο

## Βήμα 1 — Διάλεξε preset (μην ξεκινάς από το μηδέν)
Από τον τύπο της επιχείρησης, επίλεξε το κατάλληλο preset. Κάθε preset ορίζει:
**ποια sections**, **τι να ρωτήσεις**, **τι να θεωρήσεις δεδομένο**.

| Τύπος | Sections | Must-ask (ρώτα ΜΟΝΟ αυτά) | Auto (βάλ' τα χωρίς ερώτηση) |
|-------|----------|---------------------------|------------------------------|
| Ταβέρνα/Εστιατόριο | hero, μενού, κρατήσεις, ωράριο, χάρτης | πιάτα, τηλ, ωράριο, διεύθυνση | χάρτης, call button |
| Καφέ | hero, ατμόσφαιρα, μενού, ωράριο, χάρτης | περιοχή, ωράριο, τηλ | χάρτης, call button |
| Οδοντίατρος/Ιατρείο | hero, υπηρεσίες, σχετικά, ωράριο, χάρτης | υπηρεσίες, τηλ, ωράριο, διεύθυνση | χάρτης, call button, φόρμα ραντεβού |
| Μάστορας | hero, υπηρεσίες, περιοχές, τηλ | υπηρεσίες, περιοχές, τηλ | call button, badge "αυθημερόν" |
| Κομμωτήριο/Beauty | hero, υπηρεσίες, gallery, ωράριο, χάρτης | υπηρεσίες, τηλ, ωράριο | χάρτης, ραντεβού, gallery |
| Κατάστημα (γενικό) | hero, προϊόντα, ωράριο, χάρτης | τι πουλάει, ωράριο, διεύθυνση | χάρτης, call button |

> **ΚΑΝΟΝΑΣ:** Μην ρωτάς αν θέλει χάρτη ή κουμπί τηλεφώνου — κάθε τοπικό μαγαζί
> τα θέλει. Βάλ' τα αυτόματα. Ρώτα ΜΟΝΟ τα «must-ask».

## Βήμα 2 — Πάρε το template
Χρησιμοποίησε το αντίστοιχο αρχείο από `templates/` (π.χ. `dentist.html`, `taverna.html`).
Είναι static HTML με design tokens (CSS variables) για εύκολη αλλαγή χρωμάτων/γραμματοσειρών.

## Βήμα 3 — Εφάρμοσε το brand profile
Χρώματα, γραμματοσειρές, τόνος κειμένων → από το brand profile (Onboarding Agent).
Για την αισθητική, συνδυάζεται με το επίσημο `frontend-design` skill.

## Βήμα 3.5 — Δώσε 3 ΕΠΙΛΟΓΕΣ (μην επιβάλεις μία)
ΠΡΙΝ οριστικοποιήσεις, φτιάξε **3 διαφορετικές εκδοχές** του site (ίδιο preset/περιεχόμενο,
διαφορετική αισθητική). Το `frontend-design` skill το λέει ρητά: πρότεινε κατευθύνσεις,
άσε τον χρήστη να διαλέξει.

Κάθε εκδοχή = διαφορετικό **χρώμα + γραμματοσειρά + διάταξη**:
```
Εκδοχή 1 — "Ζεστή/παραδοσιακή"  (θερμά χρώματα, serif)
Εκδοχή 2 — "Μοντέρνα/μίνιμαλ"   (καθαρά, λευκά, sans-serif)
Εκδοχή 3 — "Τολμηρή/χρωματιστή" (έντονο accent, μεγάλες εικόνες)
```
Παρουσίασέ τες στον πελάτη (3 previews/links) και ρώτα: **"Ποια σου αρέσει;"**

## Βήμα 4 — Interactive refinement (συνομιλιακές αλλαγές)
Αφού διαλέξει εκδοχή, ΜΗΝ θεωρείς ότι τελείωσες. Ρώτα ενεργά:
> "Ωραία επιλογή! Θες να αλλάξω κάτι; Π.χ. να βάλω το μενού πιο πάνω,
>  να αλλάξω χρώμα, να προσθέσω φωτογραφίες;"

Δέξου αλλαγές σε φυσική γλώσσα και εφάρμοσέ τες:
- "βάλε το μενού στην αρχή" → μετακίνησε το section
- "πιο σκούρα χρώματα" → άλλαξε τα design tokens
- "πρόσθεσε φωτογραφίες από τα πιάτα" → gallery section
- "το τηλέφωνό μου είναι λάθος" → διόρθωσε

Επανέλαβε μέχρι ο πελάτης να πει "τέλειο/εντάξει". Κράτα το σε **1-tap αλλαγές**
όπου γίνεται (ο μαγαζάτορας δεν είναι τεχνικός).

## Βήμα 4 — Γράψε τα κείμενα στα ελληνικά
- Φυσικά, ζεστά ελληνικά. Όχι μεταφρασμένα κλισέ.
- Κάθε section σύντομο. CTA παντού (τηλέφωνο, ραντεβού, διεύθυνση).

## Βήμα 5 — Στοιχεία Ελλάδας
- Χάρτης: Google Maps embed με τη διεύθυνση.
- Τηλέφωνο: clickable `tel:` link + (αν δοθεί) Viber/WhatsApp.
- Domain: `.gr` (μέσω registrar — δες tech stack).

## Τι ΝΑ ΑΠΟΦΕΥΓΕΙΣ
- Λάθος section ανά τύπο (π.χ. «μενού» σε οδοντιατρείο).
- Να ρωτάς τα αυτονόητα.
- Generic «AI-looking» design (το `frontend-design` skill το αποτρέπει).
- E-shop/καλάθι — κρατάμε static, απλά sites.

## Επέκταση
Νέος τύπος επιχείρησης; Πρόσθεσε γραμμή στον πίνακα + ένα template στο `templates/`.
Ξεκίνα με 3 presets (ταβέρνα, καφέ, μάστορας), μεγάλωσε κατ' απαίτηση.
