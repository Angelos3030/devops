## Πώς το χρησιμοποιεί ο agent
1. Τύπος μαγαζιού → βρες τη γραμμή στον πίνακα.
2. Πάρε sections + must-ask + αυτονόητα.
3. Εφάρμοσε **SEO**: title/h1/meta με τα keywords («επάγγελμα + πόλη»), JSON-LD με το schema type.
4. Δες `local-seo-gr` για το πλήρες SEO checklist.

## Επέκταση (το «τα πάντα»)
Δεν υπάρχει εδώ το επάγγελμα; Πρόσθεσε γραμμή με: sections, must-ask, schema type, keywords.
**Fallback:** αν τύπος άγνωστος → χρησιμοποίησε `LocalBusiness` schema + γενικό preset
(hero, υπηρεσίες/προϊόντα, ωράριο, χάρτης, τηλέφωνο) + keywords «{περιγραφή} {πόλη}».
Έτσι καλύπτεις **οποιοδήποτε** επάγγελμα από μέρα 1.
